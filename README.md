# First PR Practice

A tiny sandbox repo for practicing the GitHub pull request workflow: branch, commit, push, open a PR, merge.

## What this is

This repo exsits so you can safely try out opening a pull request without touching real project code. Feel free to make small changes and open PRs against it.

## Getting started

1. Clone the repo
2. Create a branch
3. Make a small change
4. Push and open a PR
